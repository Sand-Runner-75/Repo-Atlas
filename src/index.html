    Settings

    GitHub token

    Optional. Adds your private repositories, the full-year contribution calendar and raises GitHub's limit from 60 to 5,000 requests an hour. Create one at github.com/settings/tokens with read-only access to Metadata and Contents.

    To run and re-run Actions from the app, also give it Actions: Read and write. Invitations, GitHub notifications and gists only work with a classic token. A classic token with the repo, workflow, read:org, notifications and gist scopes covers everything in the app.

    Help

    Getting started

    1. Add your GitHub token (optional). Click the gear at the bottom left of the window, or press Ctrl,, to open Settings. The token box is at the top. A token adds your private repositories and lets you make many more requests.
    2. Load an account or a repository. Press CtrlO, or click the account name at the top of the sidebar, then type a GitHub username, an organization or owner/repo and press Enter.
    3. Open a repository. Click one in the sidebar to preview it, or double-click to keep its tab open. CtrlP finds one by name.
    4. Follow repositories. Open a repository and click Follow, or use the bell on the left. Repo Atlas tells you about new releases, and if you like new commits, issues and failed Actions runs. Pending invitations show up there too, ready to accept.
    5. Your inbox. The inbox icon on the left (CtrlShiftM) has your GitHub notifications, your pull requests and the ones waiting for your review, issues assigned to you, your gists and your stars.
    6. Run Actions. Every repository tab lists its latest Actions runs. Re-run or cancel one, or start a workflow with Run workflow.
    7. Find any command. CtrlShiftP lists everything the app can do.
